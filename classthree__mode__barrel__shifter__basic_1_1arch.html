Detailed Description

Basic architecture with three independent shifters.

The architecture consists of three independent processes, each implementing one type of shifter. Every process produces a shifted version of the input vector a_i. Which of these results is forwarded to y_o is decided by a 4:1 multiplexer controlled by lar_i. If lar_i = "00", the input is rotated right, so y_o <= s_ror. If lar_i = "01", a logical shift right is performed, inserting zeros on the left (most significant) side, so y_o <= s_srl. If lar_i = "10", an arithmetic shift right is performed, inserting copies of the sign bit on the left, so y_o <= s_sra. If lar_i = "11", the input is passed through unchanged, so y_o <= a_i.

Process

Process implementing the arithmetic shift right.

This process performs an arithmetic shift right, filling the most significant bit positions with the sign bit of a_i, i.e. a_i(7). It is implemented with a case statement, where each branch corresponds to a shift amount given by amt_i (from 0 to 7).

Process

Process implementing the rotate-right shifter.

This process rotates the vector a_i to the right. Bits that "fall off" the right side re-enter the vector at the most significant positions. It is implemented with a case statement, where each branch corresponds to a rotation amount given by amt_i (from 0 to 7).
