Detailed Description

Optimized architecture using operator sharing.

Uses multiplexers to select operands for a single multiplier. Resource usage for DE1-SoC (5CSEMA5F31C6):

Realizacija ALMs DSP Blocks
Osnovna 26 3
Optimizovana 25 1

Savings: Optimized version uses 67% fewer DSP blocks (1 vs 3) by using operator sharing (one multiplier instead of three). ALM count is nearly identical because Quartus maps multipliers into dedicated DSP blocks, so they do not consume ALMs. ALMs are used by multiplexers and the adder: the basic version has a 16-bit 4:1 output multiplexer, while the optimized version has two 8-bit 2:1 input multiplexers and a 16-bit 2:1 output multiplexer.
