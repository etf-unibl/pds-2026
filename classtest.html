Detailed Description

2-input NAND gate

Two-input AND gate.

Two-input XOR gate.

When a_i and b_i are '1' then c_o is '0' otherwise c_o is '1'

The output y_o is '0' only when both inputs a_i and b_i are '1'. In all other cases the output is '1'.

Output y_o is the logical XOR of inputs a_i and b_i.

The output is '1' only when both inputs are '1'.
