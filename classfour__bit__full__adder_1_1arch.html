Detailed Description

Structural architecture of the four-bit full adder.

Four one-bit full adders are connected in a chain. The output carry of each stage is the input carry of the next stage.

The architecture is described in structural style. The previously designed one-bit full adder is instantiated four times. The four one-bit adders are connected in a cascade, so the carry output c_o of each adder goes to the carry input c_i of the next one. For this connection a 5-bit internal signal carry is declared, whose bits are the carries between neighbouring one-bit adders. Each instance adds one bit of the operands a_i and b_i and drives one bit of the four-bit sum_o.
