Detailed Description

Optimized architecture with a single shifter.

The basic version uses three separate shifters and a multiplexer. This version uses only one shifter. All three modes shift to the right, so they differ only in the bits that enter from the left side. These bits are called fill. The architecture works in three steps:

  1. The mode lar_i selects the value of fill.
  2. The vector extend = fill & a_i (16 bits) is created.
  3. The output is an 8-bit part (window) of extend. Its start position is given by amt_i.

In the mode "11" the output is simply a_i, so a last multiplexer selects between the shifted result and a_i. The resource usage of both implementations on the DE1-SoC chip (5CSEMA5F31C6, Optimization mode: Balanced) is given in the table:

Implementation ALMs
Basic 29
Optimized 22

The optimized version uses 22 ALMs instead of 29, which is about 24% less. The saving comes from using one shifter instead of three. Only a small multiplexer for the fill bits is added.
