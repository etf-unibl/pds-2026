Detailed Description

Architecture with a single shared leading zero counter.

The number of leading ones of a word equals the number of leading zeros of its complement. The input data is therefore conditionally inverted (each bit is xor-ed with mode_i) and a single leading zero counter is used for both modes. Instead of two counters and an output multiplexer, the design needs one counter and 16 xor gates at the input. This is functionality sharing: the leading zero counter is reused for the second function based on the relation between the two functions. The xor with mode_i is equivalent to the multiplexer (data_i when mode_i = '0' else not data_i).

RTL view of the optimized implementation

Resource usage (Flow Summary, Cyclone V 5CSEMA5F31C6, DE1-SoC):

Implementation ALMs
dual_mode_leading_counter_basic 25

The optimized implementation uses 10 ALMs less than the basic one (40 % savings). It has one leading zero counter instead of two and no output multiplexer, while the 16 xor gates at the input are merged into the LUTs of the first counter stage.
