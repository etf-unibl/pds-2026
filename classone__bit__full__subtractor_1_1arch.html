Detailed Description

Dataflow architecture of one bit full subtractor.

Full one bit subtractor is described using combinational logic using selectional concurrent statement.

Subtract port will be in high logic state if number of high logic states inputs is odd.

Carry out will be in high input state if X input port is in low logic state while either Y input port or Carry in port are in high logic state or when both terms and carry in ports are in high logic state
