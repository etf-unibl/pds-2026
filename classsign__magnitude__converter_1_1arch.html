Detailed Description

Architecture using resource sharing (single negation circuit)

Both directions negate the same operand "0" & magnitude, because bit 7 of the operand does not affect the lower seven bits of the result (128 = 0 mod 128), so no input multiplexer is needed. Only the sign bit depends on mode_i: TC->SM keeps the sign, while SM->TC converts "-0" into +0. The condition "magnitude /= 0" is taken from neg(7), i.e. from the carry chain of the incrementer, without an additional zero detector.
