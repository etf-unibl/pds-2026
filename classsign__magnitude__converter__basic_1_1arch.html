Detailed Description

Architecture using two separate converters and a multiplexer.

Contains distinct data paths for TC->SM and SM->TC conversion, each with its own complementer and incrementer. Non-negative numbers have the same representation in both formats and are passed through, while the special cases -128 and "-0" follow directly from the modular arithmetic.
